## Run Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/KhezaNabajo/Kheza-Nabajo-Portfolio-Website.git
cd Kheza-Nabajo-Portfolio-Website
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
